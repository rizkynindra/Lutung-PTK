# Audit 001, 2026-10-06

Scope: current LUTUNG PTK pages and `app/static/styles.css`, against the written direction in `DESIGN.md` and the brighter professional look requested on 2026-10-06.

Nothing in the site was changed for this audit.

## Findings

1. HIGH. R-21, R-37. Every page is black paper with yellow reading text (`#FDE100` on `#000000`) because `DESIGN.md` locks the black-and-yellow kit. That kit is what makes the portal feel harsh and flat. A brighter professional portal needs light paper, dark ink, and one restrained accent, and `DESIGN.md` has to say that before the CSS changes.
2. MEDIUM. R-06. `.section-label` is uppercase with `letter-spacing: 0.12em` on the home page, catalog, playground, technology page, API pages, and the 404 page. Wide-tracked uppercase is a default technical eyebrow, and the direction never asks for it.
3. MEDIUM. R-09. The home hero puts "Lumbung Teknologi Unggulan PTK" in that label directly above "Welcome to Lutung". The wordmark already names the product, so the line adds a label the page already states.
4. MEDIUM. R-31. Every technology card uses the same 4px yellow top border (`border-top: 4px solid var(--green)`, and `--green` is yellow). The stripe is identical on every card, so it does not mark status, category, or importance.
5. LOW. R-05. The home page's only supporting block is a 01/02/03 list: Temukan, Coba, Integrasikan. That is the fixed three-step "how it works" shape, while the catalog the direction says to prioritize is not on the page.
